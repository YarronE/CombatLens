# Design
## Inputs / constraints
Continue the user's approved v0.5 screenshot and minimal editor: no new visual direction, decorative UI, unrelated features or Plan approval gate. Current request authorizes detail improvement. Core task: click event, understand proven role/conditions/values, inspect the corresponding sample; unknowns stay explicit. Existing local evidence contains bounded rule summaries and 22 independently hash-verifiable underlying documents.
## Decisions
D1 Optional reviewed guide at local/interpretations/<adapter>/event-guide.json, or a run-local event-guide.json. New loopback GET /api/event-guide resolves only that configured document. It binds exact Build and execution source ID+SHA, verifies all summary-declared dependencies against explicitly reviewed paths under existing approved source roots, and returns only sanitized narrative/rule bindings, freshness and current package fingerprint. No research/source/copy bytes change and no case narrative ships in code.
D2 Guide entries key explicit rule IDs, may narrow action/required original values, and carry effect/conditions/boundary plus numeric references to rule or original-event fields. A generic JS builder joins them only after existing execution-rule filtering. Missing numeric paths remain unknown; literals, classname heuristics, string coercion of IDs, analyst parameter joins and inferred units are not accepted. Stage entries render separately and collapsed.
D3 Revalidate explanation source/dependencies per selection; only share in-flight summary requests, never keep stale completed results indefinitely. Use backend validity of original event sources and current fingerprint. Async completion checks object/sequence/event identity and connected nodes before paint. Fail closed on malformed guidance.
D4 New compact event summary above inspector disclosures, with effect/conditions/numbers and one frame status. Raw fields and technical rule proofs move into evidence disclosure; analysis form is a disclosure without changing save/history behavior. Necessary 13px text, existing palette/font, no extra small-text toolbar.
D5 Add pure event-sample lookup: proven action-to-clip mapping, sorted registered sample times, first sample at/after start (tiny floating tolerance only), within mapped clip bounds. Preserve original start and expose located index/time as preview state. Extend seek gate with frame intent while preserving default exact seek. Event click (including short pointer click) uses frame seek; dragging/resize remains exact preview, with no event mutation from sample quantization. Undo/redo keeps established source-coordinate behavior.
## Validation
Synthetic predicate, hash/build/JSON, dependencies/containment, missing/zero values, stage isolation, rate-one/rate-two/trimmed/missing samples, races and no-guess tests plus existing regressions. Actual local case validates known immune Buff and wrong-Buff exclusion, scan/input/unknown examples, exact located frame, analysis timing, playback/loop/history and desktop/390px. Private notes/snapshots and evidence records remain local. Document limits, scan publish inputs, verify pushed SHAs and archive specs.
