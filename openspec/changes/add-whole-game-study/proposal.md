# Whole-game study

## Why
The current action inspector cannot answer how preparation, exploration, rewards and equipment combine across a complete session. The user requested whole-game analysis using the existing local pilot, including out-of-run progression, in-run systems, relics, maps and weapon/build effects.

## Scope and decision
Add a shared game-study workspace with lifecycle/system navigation, source-bound searchable physical records and explicit references, same-frame spatial projections, and an analyst build/comparison notebook. Preserve the existing action inspector. Import the pilot's available native exports and decode additional parameter tables with its existing locked reader. Generic engineering and synthetic fixtures are public; cases remain local. Routine design choices are delegated to the agent under the current vault rule; this document is not recorded as human-reviewed approval.

## Acceptance
A user can follow a preparation-to-session-to-reward loop, inspect actual relic/weapon/effect/map records, traverse exact references without collapsing duplicate native IDs, and compare two saved build drafts. Every scope shows its version, evidence and remaining gaps. No estimated drop rate, final damage, route time or engine stacking formula is invented. Missing overlays keep legacy workspaces usable.
