# Shared instrument presentation

## Why
Researchers need a consistent workspace whose visual identity follows the selected game. Iterations validated in a local pilot must improve the shared renderer without distributing game cases.

## Changes
- Apply Swiss grid, functional typography and restrained aerospace controls to overview and action workspace.
- Accept a reviewed local presentation manifest with game artwork, attribution and palette; retain offline generic defaults.
- Explain the separate roles of CombatLens, the agent, optional REA and format readers.
- Record reusable requirements and validation in this change; case evidence stays ignored.

## Scope
Presentation and installation clarity only. No new combat interpretations, texture extraction, event dragging or runtime simulation.
