# Design v0.1
User request is executable with existing case repositories and evidence. Preserve
the approved compact Swiss/NASA dock. No new panels or visual redesign.

Freeze uses a fresh directory, content-addressed copied evidence and separate
preview root. Exact research bytes preserve identity; a new source-root maps IDs
to copied proofs. Run-local guide/presentation pin current inheritance. Compatible
copies only are included. A manifest records byte hashes and source engine commit.
Failed output remains marked incomplete. Reading/serving never imports adapters.
Fixed-path roots are explicit; this release does not promise portable relocation.

Static mode extends preview-source/1 with kind=static_mesh. Existing defaults and
rig/animation validation remain strict. The GLB inspector shares structural and
geometry checks, bypassing only rig/clip requirements in explicit static mode.
The viewer uses the same GLTFLoader/renderer but no mixer/clock for static assets.
Separate parts remain selectable; missing assembly transforms are never invented.

Case adapters remain local or in their authorized private game repo. Reuse saved
native parses and independently re-read their raw coordinate values/hashes. Keep
dual coordinates, dynamic fields and uncertain enum/task returns as original data.
Register exact native references; do not match action names by substring alone.
Review publication files, full synthetic tests and actual browser geometry,
source/copy isolation, frozen reopen and no-clock fallback before push.

Ownership: shared code in this repo; case adapter/integration in private game repo;
all game inputs/bundles/outputs/screenshots ignored. No original game writes.
Acceptance: closed local prior-case bundle; generated second-case real geometry;
native source coordinates and links preserved; copy save/reopen; public scan clean.
