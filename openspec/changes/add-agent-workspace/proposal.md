# Add agent workspace

Action-game players and combat designers need a repeatable request-to-workspace
flow instead of manually joining files, events and animations. The owner has
authorized implementation based on the reviewed product design and a real local
pilot. Pilot data and adapter implementation are excluded from public Git.

Add a natural-language CLI request, explicit adapter contracts, source validation,
stage reports, a generic research overview and an existing source-backed action
editor. Add a distributable agent Skill and synthetic public verification.
Reuse authored runtime code; do not modify the original prototype or game files.

Capability boundaries are request routing, adapter preparation, research viewing,
analysis persistence and reproducible agent handoff. This change does not provide
universal game support or a full game-runtime simulator.
