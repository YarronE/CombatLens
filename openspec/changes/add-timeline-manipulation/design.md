# Design
## Context
app.js edits cloned analysis objects, model.js validates overrides, PreviewSeekGate checks current contexts, and the server protects original fields and revisions. Current edits have no history. No REA operation participates in pointer interaction.
## Decisions
D1: Add pure timing transforms and an event-scoped command history module. Store only overrides for originals and indexed payloads for analyst-created events; avoid full research snapshots. Each command has copy/object/sequence/event identity. Cap at 100 commands and track monotonic state tokens for saved checkpoints. Server revisions and analysis identity are never replayed.
D2: Pointer capture on SVG event groups. Freeze the axis domain at gesture start; convert client X through the current SVG screen matrix. Body movement preserves duration; handles retain a strictly non-inverted interval. Snap is a delta in native units, never inferred FPS. Preview only the dragged group during movement; commit once on release. Escape/cancel/blur/lost capture restores without history. A short click selects only. Retain scroll/focus after rerender. Pack overlapping events into display lanes within their native track; source track values stay unchanged. Render the selected event above neighbors so its edge handles remain targetable.
D3: Shared history wrapper for form edits, additions, hiding/deletion, reset and hidden-event restoration. Pending form input is committed before workspace undo. Native input undo and dialogs are excluded from global shortcuts. Open/import/save-as reset the history; original-mode viewing only disables controls. Save sets a checkpoint but does not clear history. Disable mutation/copy replacement during an in-flight save.
D4: Coalesce pointer preview on animation frames through PreviewSeekGate. Use the manipulated edge time for preview, restore previous clip time on cancellation, and seek selected effective time after undo/redo. Retain proven mapping, source/clock boundaries and subject isolation.
## Trade-offs
History is session-only and bounded; saved values remain portable in the existing schema. Displayed domain bounds pointer operations; the form remains available for values outside it. No speculative game-speed conversion. No REA fork for a client-side editing requirement.
## Validation
Pure synthetic tests for timing boundaries, unit steps, scoped commands, immutable originals, checkpoints/branching and revisions. Existing source/save and preview tests remain. Actual browser tests must exercise pointer drag, both handles, undo/redo, save/reopen, model time and read-only/narrow layouts. Shared pointer lifecycle cancellation is verified deterministically with EventTarget tests for Escape, pointer cancel, lost capture and window blur; do not label those synthetic checks as human browser actions. Local case outputs/screenshots stay ignored.
