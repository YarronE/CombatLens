# Local analysis bundle
- Freeze a selected, source-current research run into a new destination only.
- Include pinned shared runtime bytes, exact research/timeline bytes, all registered
  evidence, registered preview files, reviewed presentation/guide and compatible
  saved analysis copies. Extra selected acceptance files may be attached.
- Deduplicate evidence by digest; rebind only local registries/overlays. Preserve
  source IDs, Build, package fingerprint, original values and copy revisions.
- Copy no credentials, adapter executable, game install or unrelated analysis.
- Refuse existing destinations and stale inputs. Failed output is explicitly
  incomplete, never active. Never change the source active pointer or files.
- Hash every delivered file in a private receipt. Reopen with the bundled runtime
  and validate all evidence and guide dependencies independently of source roots.
- This is a fixed local installation snapshot; relocation requires rebinding.
  Bundles contain private data and must stay outside all tracked file sets.

- The analysis catalog lists only the exact current Build and package fingerprint.
  Other cases remain on disk and in their own research contexts; no deletion or
  cross-case original-data replacement occurs.
