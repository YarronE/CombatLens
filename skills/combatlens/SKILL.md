# CombatLens

使用 `scripts/run.py` 调用工具。先运行 `doctor` 与 `adapters`，复用已登记路径，
将用户研究问题原样作为 `analyze` 的请求参数传入，不拼成 shell 命令。

已支持的目标使用 `analyze "用户的研究请求" --open`。打开返回的URL，检查
对象、来源和动画是否实际载入。交付URL、Markdown及结构化记录，说明本轮实际
做了提取、导入或重建的哪些步骤，保留尚未恢复的字段和单位。

缺适配器时先阅读项目 `docs/ADAPTERS.md`。确认用户的本地游戏或资源路径，
以REA的具体工具检查目标格式、程序与证据，再复用合适读取器编写本地适配。
新适配器保存在ignored local目录，核对真实样本后登记，不能因引擎相同就
宣称兼容。路径可从已配置资料确定时不重复询问，确实缺失时只问必要位置。

REA通过CLI或Agent已有MCP使用。先检查可用工具和版本，保留Evidence导出、
目标摘要、覆盖与限制。已有研究足以回答问题时不重复深层反编译。没有工具
结果时如实报告，不把连接成功、动画姿态或生成页面当作原作机制验证。

原游戏与原始证据只读。修改另存研究副本。事实、自述与推测分别标明，
未知时间不补零。公有仓库不保存真实案例、密钥或游戏资产，截图另行选择。

工具尚未支持任意游戏自动完整还原。对新目标持续完成可验证的适配与研究，
把未恢复部分写入运行报告，不能静默用合成演示替代用户目标。

生成工作台时使用工具当前共享页面，不为单款游戏复制一份独立前端。
先复用已登记主题；需要新主题时，按 docs/ADAPTERS.md 的 presentation 契约
在 local/presentations/<adapter-id>/ 保存主视觉、来源与摘要，配置游戏名称和
六位十六进制配色。查找官网或用户提供的主视觉，记录图片颜色采样与实际包内
样本范围；缺少贴图就保留缺口，不把官网取色写成整包统计。默认布局在无图片
时仍须可用。实际打开概览与动作页，核对主视觉、字体、对象隔离和 Timeline。

查看已有研究无需安装REA。REA用于需要它的程序调查，且与CombatLens分开连接；
已有MCP连接直接复用。对应格式读取器、codec与输入文件依适配器单独检查。
